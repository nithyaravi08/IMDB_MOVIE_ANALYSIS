# 🎬 IMDB Movie Analysis

This project is an **end-to-end data analytics workflow** on the IMDB 5000 Movie Dataset, analyzing movie performance and trends across various parameters.


## ✨ Objective
To analyze movie data and extract actionable insights on **budgets, revenues, genres, directors, and IMDb ratings** using multiple analytical tools.


## 🛠 Tools Used
- **Python (Jupyter Notebook / IDLE):** Data cleaning and exploratory data analysis (EDA).  
- **Libraries:** Pandas, NumPy, Matplotlib, Seaborn.  
- **Excel:** Pivot tables, conditional formatting, and dashboard creation.  
- **SQL / MySQL:** Writing queries for structured data extraction.  
- **Power BI:** Interactive dashboards and advanced visualizations.  
- **GitHub:** Version control and project hosting.  
- **MS Word / PDF:** Final report documentation.


## 📌 Features Implemented

- **Data Cleaning:** Handling missing values, removing duplicates, and renaming columns.  
- **Univariate Analysis:** Distribution of IMDb ratings, budgets, gross, and movie durations.  
- **Bivariate Analysis:** Relationships between Budget vs Gross, Genre vs IMDb rating, etc.  
- **Visualizations:** Histograms, scatter plots, boxplots, heatmaps (Python), Excel charts, and Power BI dashboards.  
- **Pivot Analysis (Excel):** Top 10 highest-grossing movies, average IMDb rating per genre, and yearly movie trends.  
- **SQL Queries:** Top 5 movies by rating, average IMDb per director, movies with gross > 100M, count per genre, director with most movies.  
- **Dashboarding (Excel & Power BI):** Interactive dashboards with slicers, KPIs, and trend analysis.  
- **Report Writing:** Summarizing methodology, insights, and conclusions in the final report.


## 🎯 Project Goal
To provide **insights-driven analysis** of the IMDB movie dataset, demonstrating data cleaning, exploratory analysis, SQL querying, visualization, and dashboarding skills.
